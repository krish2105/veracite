## 4. The prompt to paste into Claude Code
```
I'm Zedan (Team 7, Trust/Ethics/QA lead) on our hackathon project Veracite.

1. Read CLAUDE.md, docs/HANDOFF.md, docs/OWNERSHIP.md, tasks/zedan.md and veracite/tests/golden/README.md. Then tell me your plan in 5 bullets and wait for my OK.

   - real.json (30): real, peer-reviewed papers across business/management, AI/computer science, health and education. Verify EVERY DOI live against the Crossref REST API (https://api.crossref.org/works/{doi}). Title, first author and year must match Crossref exactly. "raw" = a correct APA 7 reference.
   - fabricated.json (20): do NOT invent these yourself. I will paste references generated by ChatGPT/Gemini; keep them exactly as pasted. Check each with Crossref (https://api.crossref.org/works?query.bibliographic=...&rows=3). If any turns out to be real, tell me and move it to real.json or mark it "mismatch".
   - chimeras.json (10): build from real.json by mixing parts of two real papers (e.g. title of one + authors and year of another). In "notes", say exactly which part came from which DOI.
   - retracted.json (5): real retracted papers. Find them via https://api.crossref.org/works?filter=update-type:retraction&rows=30, then verify each original DOI and its retraction notice.
   - web.json (5): real, stable web pages (e.g. WHO, OECD, UNESCO, UAE government reports) with URL and retrieval date; check each URL loads.
   - Every record uses exactly the format in the README: {"id","sample":true,"raw","expected","doi","notes"}. No personal data.

3. Add veracite/tests/golden/validate.mjs (plain Node, no dependencies) that checks the JSON shape, the counts (30/20/10/5/5) and that no DOI is duplicated. Run it and show me the output.

4. When it passes: tick Z01 as [x] in tasks/zedan.md, add a row to docs/PROMPT_LOG.md (date, me, Claude Code, the prompts used, including my ChatGPT/Gemini prompt for the fakes), run `npm run status`, then commit on a new branch zedan/Z01-golden-set with the message "Z01: golden test set". No Co-Authored-By or any AI attribution lines. Push and open a PR into main with `gh pr create --fill`.

Ask me before touching anything outside these files.
```
