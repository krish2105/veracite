(point at a challenge) And this is the Skeptic: a different model family, with no shared memory, whose only job is to disagree. I keep, edit or drop each claim. (approve) Checkpoint three. The student stays in charge the whole way.

When the AI is off (no key, or Groq is down)

The AI is switched off right now, and I want to show you that on purpose. (Start) In Rules mode, the plan is my question as I typed it. The searching and checking still run, because they’re code, not AI. I still approve the plan and choose the sources. The only thing missing is the AI drafting, and Veracite tells you that plainly instead of faking it.

Why this works: it shows the workflow from the deck live (plan → sources → claims) and the two separations that matter: the Verifier is code, and the Skeptic is a different model. The labels are the honesty system the judges asked for.

Q&A: who answers, and what to say

The owner answers first. If someone else built it, hand over in one sentence: “Zedan built that part.” Give a number or a click wherever you can. If you don’t know: “We haven’t measured that yet. What we have measured is…”

K How do you stop the AI inventing references?
It can’t output one. Its answer format only accepts IDs of records we fetched from Crossref, OpenAlex or arXiv. An invented ID is blocked by code and logged. Prompts aren’t the guardrail; code is.
K What if Crossref and OpenAlex disagree?
Then it isn’t Verified. It says Mismatch or Partial, and the table shows what you typed against what each registry says.
Show: X-ray → the Kestin year-mismatch row
K What if the AI goes down during the demo?
A fallback model first, then Rules mode, which still verifies every reference. Want to see? I’ll switch AI off now.
K Can it read paywalled papers?
No, and it says so. Quotes are checked against abstracts only, so anything deeper stays “Reported, not checked”, never Verified. When a registry lists a free legal copy, we link to it.
K What’s the weakest part?
Web pages: three out of five in our tests, so they’re capped at Partial with the date retrieved. And reports written by organisations, like UNESCO, can trip the chimera check. We publish both.
K Did you use AI to build this?
Yes, AI coding tools, under our direction. Every prompt is in our prompt log, as rule 8 requires. The honesty decisions are ours.
Z Where does student data go?
Nowhere we store it. No accounts; the library lives in your browser. Code strips emails, phone numbers and IDs before anything reaches the AI. A certificate carries its data inside the link.
Z Who is accountable if a citation is wrong?
The student is the author: they approve the plan, the sources and every claim. We’re accountable for our checks: they’re plain code, and we publish the test results. Faculty can re-check any list from the certificate.
Z Doesn’t this make students lazier?
It’s built for the opposite: three approvals, an AI dial that goes to Off, read-before-you-cite, and the student writes every word in Write & cite.
Z Why not detect AI-written essays?
Detectors falsely accuse people. A Stanford study found they flagged 61 % of essays by non-native English writers. We check sources, not people.
A Why would a student switch from Zotero?
They don’t have to. Import your Zotero file, keep only the references that are real, and export back to Zotero or Mendeley.
A Why 3D? Isn’t it decoration?
The 3D is the idea: a UV lamp shows what’s real. Every check also has a plain table, and Plain view turns the 3D off.
A How would SP Jain roll this out?
It’s free, there are no accounts, and it works in a browser, even on a phone. Faculty accept the QR certificate with a submission. We could pilot it with one cohort in a week.

How Veracite works, in plain words

The six verdicts (code sets them; no AI)

LabelWhat it meansHow code decides
VerifiedThis paper exists and matches what you typed.Crossref and OpenAlex both have it; DOI, title, first author and year agree.
PartialIt probably exists, but we can’t confirm everything.Only one registry has it, or only a DOI was given, or it’s a web page.
MismatchThe paper exists, but a detail you typed is wrong.A field differs from the registry, e.g. the year 2021 against 2025.
ChimeraStitched from real parts that don’t belong together.The title, authors and DOI point to different records.
RetractedThe paper was withdrawn. Don’t cite it.A retraction notice is linked to it (Retraction Watch, via Crossref).
Not foundNo registry has anything like it.Every search came back empty; the searches are listed as receipts.

The labels on AI sentences

● Verified the quoted words really are in the source’s abstract · ◐ Reported, not checked the source says it, but we couldn’t confirm the quote · ◆ AI reasoning the AI’s own words, with no source behind them · ⊘ Not found no source supports it. Shapes as well as colours, so the labels work for colour-blind users too.

The seven agents

Planner (AI) turns your question into searches · Scout (code) searches the registries · Verifier (code, no AI) checks every record · Reader (AI) pulls exact quotes from abstracts · Scribe (AI) drafts claims from approved sources only · Skeptic (AI, a different model) challenges each claim · Integrity Clerk (code) builds the reference list, AI-use statement and certificate.

What’s AI, and what’s code

AI may: suggest search terms, explain abstracts, draft labelled claims, argue against them. Only code may: write a reference, set a label, decide Verified, format a citation, add anything to your list (and only after your click). That split is the whole design.

The side doors

Paste a chatbot’s answer (uncited author–year claims are flagged) · drop a PDF (read in the browser, never uploaded) · import a .bib or .ris library · save a page from any site with the bookmarklet (web pages are Partial, with the date retrieved) · re-check the library for retractions since you saved. All go through the same Verifier.

When things fail

Model busy → a fallback model. AI down or off → Rules mode: every check still runs, nothing is drafted, and a banner says so. A registry doesn’t answer → “could not be checked”, never a guess. Test and sample data are always labelled SAMPLE.

Words judges might use

DOI: a permanent ID for a paper, like 10.1038/nature14539. Crossref: the registry publishers use to register DOIs. OpenAlex: a free, open index of hundreds of millions of scholarly works. arXiv: a preprint server. CSL: Citation Style Language, the open style files Zotero uses too. MCP: Model Context Protocol, a standard way for AI tools to call other tools. Hallucination: when a model states something false with confidence.
